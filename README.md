# KinoTube

YouTube загвартай, өөрийн кино файлуудаар ажилладаг React (Vite) сайт.

## Ажиллуулах

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ хавтсанд бэлэн сайт гарна
```

## Кино нэмэх

1. Видео файлаа `public/videos/` хавтсанд хуулна (жишээ нь `public/videos/metropolis.mp4`).
2. Зургаа (16:9 харьцаатай) `public/thumbnails/` хавтсанд хуулна. Зураг байхгүй бол сайт киноны нэрээр өнгөт зураг өөрөө үүсгэнэ.
3. `public/movies.json` файлд нэг мөр нэмнэ:

```json
{
  "id": "metropolis",
  "title": "Метрополис",
  "year": 1927,
  "genres": ["Шинжлэх ухааны уран зөгнөлт", "Драм"],
  "duration": "2:33:00",
  "description": "Киноны товч агуулга",
  "video": "videos/metropolis.mp4",
  "thumbnail": "thumbnails/metropolis.jpg",
  "added": "2026-10-18"
}
```

- `id` нь давтагдахгүй, латин үсэг, зураасаас бүрдэнэ (хаягт `#watch-metropolis` гэж харагдана).
- `genres` дахь нэрүүдээр хажуугийн цэс болон шүүлтүүр автоматаар үүснэ.
- `video` нь `.mp4` (H.264) байвал бүх хөтөч дээр тоглоно.

Одоогийн `movies.json` дахь 10 кино нь жишээ өгөгдөл. Өөрийнхөөрөө солиорой.

## Үзсэн түүх

- `#history` хуудас (YouTube маягийн): үзсэн кинонууд өдрөөр бүлэглэгдэнэ (Өнөөдөр, Өчигдөр, Энэ долоо хоног...), хаана хүртэл үзсэн нь бичигдэнэ.
- Кино үзэж байхад 5 секунд тутам, зогсоох/гарах үед байрлал хадгалагдана. Дахин ороход зогссон газраасаа үргэлжилнэ ("Эхнээс нь үзэх" товчтой).
- Зураг дээрх улаан зурвас хэдэн хувь үзсэнийг харуулна (нүүр, санал болгох, түүх, профайл).
- Түүхээс хайх, нэг киног хасах, бүх түүхийг устгах боломжтой. Түүх хэрэглэгч бүрт тусдаа (localStorage).

## Нэвтрэх, профайл, данс

- Хэрэглэгч утасны дугаар болон 4 оронтой кодоор нэвтэрнэ (`#login`). Шинэ хэрэглэгч `#register` хуудсаар бүртгүүлнэ.
- "Кодоо мартсан уу?" (`#forgot`): утас руу 6 оронтой код илгээж, шинэ 4 оронтой код үүсгэнэ.
- Профайл (`#profile`): нэр, утас, дансны үлдэгдэл, цэнэглэлт, үзэх эрх ("1 сарын эрх 2026.11.01-нд дуусна"), үзсэн түүх, гүйлгээний түүх.
- Эрхгүй хэрэглэгч кино үзэх гэвэл "Эрх авах" товч гарна.
- Үнийг `src/auth.js` доторх `PLANS`, цэнэглэх дүнг `TOPUP_AMOUNTS`-оос өөрчилнө.

**Анхаар:** одоогоор сервер байхгүй тул бүх мэдээлэл хэрэглэгчийн хөтөч дотор (localStorage) хадгалагдана. SMS илгээхгүй (код дэлгэцэнд харагдана), төлбөр жинхэнээр авахгүй. Жинхэнэ сайт болгохдоо `src/auth.js` доторх функцуудыг сервер (SMS үйлчилгээ, QPay гэх мэт төлбөрийн систем) рүү дуудлагаар солих хэрэгтэй.

## Shorts

- `#shorts` хуудас: YouTube Shorts шиг босоо бичлэгүүд, дээш/доош гүйлгэж (эсвэл ↑ ↓ товч) шилжинэ. Идэвхтэй бичлэг дуугүй автоматаар тоглоно, дууг баруун доод товчоор нээнэ. Хаяг нь `#shorts-<id>` болж шинэчлэгдэнэ.
- Нүүр хуудсанд Shorts мөр харагдана (жанр сонгоогүй, хайлтгүй үед).
- Бичлэгийг `public/shorts.json`-д нэмнэ: `id`, `title`, `duration` ("М:СС" эсвэл "Ц:ММ:СС"), `description`, `video`, `thumbnail` (9:16), `movie` (заавал биш, бүтэн киноны `id`), `added`.
- **Урт нь дээд тал нь 20:00.** Үүнээс урт эсвэл `duration`-гүй бичлэгийг сайт харуулахгүй, console-д анхааруулга бичнэ (`src/data.js`-ийн `SHORTS_MAX_SECONDS`).
- Shorts үзэхэд нэвтрэх, эрх шаардахгүй.
- Одоогийн 8 бичлэг жишээ өгөгдөл, видео файл нь хараахан байршаагүй тул "Видео удахгүй нэмэгдэнэ" гэж харагдана.

## Deploy

`main` руу push хийхэд Vercel автоматаар https://kinotube.vercel.app дээр гаргана. GitHub Actions (`.github/workflows/ci.yml`) push болон PR бүрт build шалгана.
