# KinoTube

YouTube загвартай, өөрийн кино файлуудаар ажилладаг React (Vite) сайт.

## Ажиллуулах

```bash
npm install
cp .env.example .env.local   # Зугаагийн Supabase болон апп-ын хаягийг бөглөнө
npm run dev        # http://localhost:5173
npm run build      # dist/ хавтсанд бэлэн сайт гарна
```

## Кино нэмэх

1. Видео файлаа `public/videos/` хавтсанд хуулна (жишээ нь `public/videos/metropolis.mp4`).
2. Зургаа (16:9 харьцаатай) `public/thumbnails/` хавтсанд хуулна. Зураг байхгүй бол сайт киноны нэрээр өнгөт зураг өөрөө үүсгэнэ.
3. `public/movies.json` файлд нэг мөр нэмнэ:

```json
{
  "id": "metropolis",
  "title": "Метрополис",
  "year": 1927,
  "genres": ["Шинжлэх ухааны уран зөгнөлт", "Драм"],
  "duration": "2:33:00",
  "description": "Киноны товч агуулга",
  "video": "videos/metropolis.mp4",
  "thumbnail": "thumbnails/metropolis.jpg",
  "added": "2026-10-18"
}
```

- `id` нь давтагдахгүй, латин үсэг, зураасаас бүрдэнэ (хаягт `#watch-metropolis` гэж харагдана).
- `genres` дахь нэрүүдээр хажуугийн цэс болон шүүлтүүр автоматаар үүснэ.
- `video` нь `.mp4` (H.264) байвал бүх хөтөч дээр тоглоно.

Одоогийн `movies.json` дахь 10 кино нь жишээ өгөгдөл. Өөрийнхөөрөө солиорой.

## Нэвтрэх, профайл, төлбөр (Зугаатай нэгдсэн)

KinoTube нь [Зугаа](https://github.com/bayrtsogt/zugaa)-гийн Supabase төсөл, бүртгэл, төлбөрийн системийг дундаа
ашиглана. Зугаагийн хэрэглэгч KinoTube-д тэр чигээрээ нэвтэрнэ.

- **Нэвтрэх** (`#login`): имэйл → 6 оронтой код. Бүртгэлгүй бол код оруулахад шинээр үүснэ.
- **Профайл** (`#profile`): нэр (засах), имэйл, үзэх эрх ("2026.11.20-нд дуусна", үлдсэн хоног), эрх авах/сунгах,
  үзсэн түүх, төлбөрийн түүх.
- **Төлбөр** (`#pay-<id>`) — Зугаагийнхтай яг ижил:
  1. Эрх сонгоход `ZG-1234` гүйлгээний утгатай хүсэлт үүснэ. Дүнг сервер `products` хүснэгтээс авна.
  2. Дүн, банк, дансны дугаар, хүлээн авагч, гүйлгээний утга "Хуулах" товчтой харагдана.
  3. Хэрэглэгч банкаар шилжүүлээд **"Гүйлгээ хийсэн"** дарна.
  4. Зугаагийн **Telegram бот** админуудын группт `Шинэ төлбөр — ZG-1234 · Апп: KinoTube` мессежийг
     **✅ Батлах / ❌ Татгалзах** товчтой илгээнэ.
  5. Админ ✅ дармагц эрх нээгдэж, KinoTube-ийн нээлттэй хуудас өөрөө "Эрх нээгдлээ" болно (Realtime, 10 секундын
     шалгалт нөөц). ❌ дарвал "Төлбөр баталгаажсангүй"; админ тэр мессежид хариу бичвэл шалтгаан болж харагдана.
  6. Хүсэлт 24 цагийн дотор "Гүйлгээ хийсэн" болоогүй бол хүчингүй болно.
- Төлбөр хүлээн авах данс `src/auth.js` доторх `BANK`-д бий.
- Эрхийн үнэ, хугацааг Зугаагийн `products` хүснэгтэд (`app = 'kino'`) өөрчилнө. KinoTube-ийн эрх зөвхөн кино
  нээнэ; Зугаагийн бүх апп-д зориулсан (`app = 'all'`) эрх кино ч нээнэ.
- Үзсэн түүх хөтөч дотор (localStorage), хэрэглэгч бүрт тусдаа хадгалагдана.

### Тохиргоо

1. Зугаагийн сервер дээр `kino` эрхүүдийг нэмж, `CORS_ORIGINS`-д KinoTube-ийн хаягийг оруулна (Зугаагийн README →
   "KinoTube").
2. Зугаагийн Supabase → Auth → Rate limits: KinoTube-д код хэрэглэгчийн хөтчөөс шууд хүсэгдэнэ.
3. `.env.local`:

| Хувьсагч | Утга |
| --- | --- |
| `VITE_SUPABASE_URL` | Зугаагийн Supabase URL |
| `VITE_SUPABASE_ANON_KEY` | anon (publishable) түлхүүр |
| `VITE_ZUGAA_URL` | Зугаа апп-ын хаяг (`APP_URL`) |

Тохируулаагүй үед кино жагсаалт ажиллана, нэвтрэх хуудас тохиргоо дутуу гэж анхааруулна.

**Анхаар:** видео файлууд `public/videos/` дотор нийтэд нээлттэй байршдаг тул эрхийн шалгалт зөвхөн дэлгэц дээр
хийгдэнэ. Видеог жинхэнээр хамгаалахын тулд эрх шалгадаг сервер эсвэл хугацаатай холбоос (signed URL) хэрэгтэй.
