# KinoTube

YouTube загвартай кино үзэх сайт: React (Vite), Supabase (хэрэглэгч, эрх, төлбөр), Cloudflare Pages + Functions (сервер), Cloudflare R2 (видео).

## Бүтэц

| Хэсэг | Хаана |
| --- | --- |
| Сайт (React) | `src/`, Cloudflare Pages дээр `dist/` |
| Сервер | `functions/api/` (Cloudflare Pages Functions), туслах код `server/` |
| Өгөгдлийн сан | Supabase: `supabase/migrations/` (хүснэгт, RLS, төлбөрийн функцууд), тест `supabase/tests/` |
| Кино жагсаалт | Supabase `catalog` хүснэгт (админаас нэмнэ) |
| Видео, зураг | Cloudflare R2 bucket `kinotube`: `movies/<id>.mp4`, `episodes/<id>/<анги>.mp4`, `thumbnails/...` |
| Төлбөр | Хаан банкны шилжүүлэг → Telegram ботоор админ батална |

## Ажиллуулах

```bash
npm install
cp .env.example .env   # VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY
npm run dev            # http://localhost:5173 (зөвхөн сайт, /api ажиллахгүй)
npm run build          # dist/
npm test               # R2 линкийн гарын үсгийн тест
```

Сервертэй хамт: `.dev.vars` файлд серверийн утгуудыг бичээд (`.env.example`-ийг харна)
`npm run build && npx wrangler pages dev dist`. `.env`, `.dev.vars` git-д орохгүй.

Өгөгдлийн сангийн тест: `npx supabase test db` (Supabase CLI, Docker хэрэгтэй).

## Кино нэмэх (админаас)

Кино, цувралын жагсаалт Supabase-ийн `catalog`, ангиуд `episodes` хүснэгтэд, видео, зураг Cloudflare R2-д хадгалагдана. JSON засах, git-д push хийх шаардлагагүй.

1. Админ → **Кино** → **Кино нэмэх** (олон ангитай бол **Цуврал / Shorts** → **Цуврал нэмэх**, доорх "Олон ангитай кино"-г харна). **Хэлбэр**: хэвтээ эсвэл босоо.
2. Нэр бичихэд хаягийн ID (`#watch-<id>`) кирилл нэрээс латин үсгээр автоматаар гарна (засаж болно, хадгалсны дараа өөрчлөгдөхгүй).
3. **Видео (MP4)** сонгоход урт нь автоматаар бөглөгдөнө. **Зураг** (хэвтээ 16:9, босоо 9:16) JPG/PNG/WEBP.
   - **Видеоноос нүүр сонгох**: видео сонгомогц 6 кадр гаргаж, хамгийн тод, дэлгэрэнгүйг нь автоматаар нүүр болгоно (харанхуй, титрийн кадрыг алгасна). Өөр кадр дээр дарж солино, "Өөр кадрууд" дахин гаргана. Босоо видеог кинонд 16:9 бүдгэрүүлсэн дэвсгэртэй болгоно. Засахад R2 дээрх видеоноос "Кадрууд гаргах".
   - Жагсаалтын дээрх **Нүүр сонгох (N)** товч: зураггүй, видео нь байршсан бүх бичлэгт нэг дор автомат нүүр тавина (`src/frames.js`, R2 CORS GET шаардлагатай).
4. **Хадгалах** дармагц мэдээлэл хадгалагдаж, видео арын дараалалд хуулагдаж эхэлнэ. Дараагийн киногоо шууд нэмж болно, зэрэг 2 видео хуулна, бусад нь дараалалд.
   Хуулж байхад сайт дотор шилжиж болно (баруун доод буланд явц харагдана), харин хөтчийн цонхыг хаавал зогсоно.
5. Видео хуулж дуусахад Telegram группт "📤 Видео байршлаа" мессеж очиж, "Сайтад нийтлэх" сонгосон бол кино хэрэглэгчдэд шууд харагдана. Тасарвал "⚠️" мессеж очно, админ "Дахин оролдох" дарна.
6. Нийтлээгүй (ноорог) кино зөвхөн админд харагдана.

- Видео: MP4 (H.264 + AAC) бүх хөтөч дээр тоглоно. MKV, HEVC бол эхлээд хөрвүүлнэ: `scripts/prepare-video.sh кино.mkv <id>` (ffmpeg, 720p).
- Том файлыг 32 MB+ хэсгүүдэд хувааж R2 руу шууд хуулна (50 GB хүртэл). R2 замууд: `movies/<id>.mp4`, `episodes/<id>/<анги>.mp4` (хуучин Shorts: `shorts/<id>.mp4`), `thumbnails/...`.
- Сайт видеог шууд биш, серверээс авсан 6 цагийн хугацаатай линкээр тоглуулна (`functions/api/video/[id].js`): эрхгүй хүн бүтэн видеоны линк авч чадахгүй (кинонд зөвхөн эхний 5 минутын байтыг `/api/preview/<id>` дамжуулна). Зураг `/img/thumbnails/...` (`functions/img/`).
- **Хадмал** (заавал биш): `catalog.subtitles` = `"subtitles/x.mn.vtt"` эсвэл `[{ "src", "lang", "label" }]`, файл нь `public/subtitles/`-д.
- Supabase тохируулаагүй локал хөгжүүлэлтэд (`.env`-гүй) `public/movies.json`, `public/shorts.json`-оос уншина.

### R2 CORS (нэг удаа)

Хөтчөөс шууд хуулахын тулд Cloudflare → R2 → `kinotube` → Settings → **CORS Policy**:

```json
[
  {
    "AllowedOrigins": ["https://kinotube.pages.dev", "http://localhost:5173"],
    "AllowedMethods": ["GET", "HEAD", "PUT"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]
```

`ExposeHeaders: ETag` заавал хэрэгтэй (хэсгүүдийг нийлүүлэхэд). Өөр домэйн холбовол `AllowedOrigins`-д нэмнэ.

## Кино тоглуулагч

- `src/components/Player.jsx`: өөрийн удирдлагатай тоглуулагч. Зогсоох/тоглуулах, гүйлгэх зурвас, 10 секунд ухраах/урагшлуулах товч, дуу, бүтэн дэлгэц.
- Утсан дээр хоёр товшиж зүүн тал −10, баруун тал +10 секунд. Компьютер дээр: зай/K зогсоох, ← → 10 секунд, F бүтэн дэлгэц, M дуу.
- Утсан дээр тоглуулагч босоо 9:16, дэлгэцэд багтах хэмжээтэй (Reels маягийн бичлэг дэлгэцийг дүүргэнэ). Хэвтээ бичлэг ачаалагдвал 16:9 болж жижгэрнэ. Компьютер дээр 16:9. Бүтэн дэлгэцэнд дэлгэцийг бүхэлд нь эзэлнэ; хэвтээ кино Android дээр дэлгэцийг хэвтээ болгоно, босоо (9:16) бичлэг утсаа босоо барихад дэлгэцийг дүүргэнэ. iPhone дээр iOS-ийн өөрийн бүтэн дэлгэц нээгдэнэ.
- Видео файл байхгүй бол "Энэ кино удахгүй нэмэгдэнэ" гэж харагдана.
- Үнэ: **нэг кино 4,900₮** (тухайн киног 3 хоног үзнэ), **сарын эрх 15,900₮** (бүх кино). Жинхэнэ үнэ Supabase-ийн `products` хүснэгтэд (Table Editor-оос өөрчилнө), сайт дээр харагдах үнэ `src/auth.js`-ийн `RENTAL`, `PLANS`-д. Хоёуланг нь өөрчилнө. Кино тус бүрийн үнийг админ → Кино → засах хэсгийн "Үнэ" талбараас тохируулна (`catalog.price_mnt`); хоосон бол 4,900₮.
- Нэвтрээгүй үед тоглуулагч дээр хоёр үнэ ба "Нэвтрэх" товч гарна. Эрхгүй үед хоёр сонголт гарч, дармагц төлбөрийн хуудас (`#pay-rent-<id>` / `#pay-month-<id>`, профайлаас `#pay-month`, `Checkout.jsx`) руу орно. Төлбөрийн дараалал доор.
- Тоглуулагчийн доор: **Дараа үзэх**, **Хадмал** (хадмалтай кинонд), **Хурд** (0.75×–2×).
- Товчлол (дээрхээс гадна): C хадмал асаах/унтраах, `<` `>` тоглуулах хурд.

## Ангилал

- Ангилал: AI кино (эхэнд), Хуучны кино, Монгол кино, Хятад кино, Солонгос кино. Нүүрэнд ангилал бүр өөрийн мөртэй (кинотой бол), "Бүгдийг үзэх" нь тухайн ангиллын бүх кино руу. Админ кино бүрт сонгоно (нэг кино хэд хэдэнд орж болно), нүүрэнд чипээр шүүнэ, `#cat-<old|ai|mongolian|chinese|korean>` хаягаар шууд нээгдэнэ. Жагсаалт `src/data.js`-ийн `CATEGORIES`, серверт `catalog.categories`.

## Дараа үзэх

- `#later` хуудас: үзэх хуудсан дээрх "Дараа үзэх" товчоор хадгалсан кинонууд. "Түүх" хуудасны хажуугийн хэсгээс орно. Хэрэглэгч бүрт тусдаа (localStorage), нэвтэрсэн үед.

## Үзсэн түүх

- `#history` хуудас (YouTube маягийн): үзсэн кинонууд өдрөөр бүлэглэгдэнэ (Өнөөдөр, Өчигдөр, Энэ долоо хоног...), хаана хүртэл үзсэн нь бичигдэнэ.
- Кино үзэж байхад 5 секунд тутам, зогсоох/гарах үед байрлал хадгалагдана. Дахин ороход зогссон газраасаа үргэлжилнэ ("Эхнээс нь үзэх" товчтой).
- Зураг дээрх улаан зурвас хэдэн хувь үзсэнийг харуулна (нүүр, санал болгох, түүх, профайл).
- Нүүр хуудсан дээр "Үргэлжлүүлэн үзэх" мөр: дуусгаагүй кинонууд.
- Түүхээс хайх, нэг киног хасах, бүх түүхийг устгах боломжтой. Түүх хэрэглэгч бүрт тусдаа (localStorage).

## Нэвтрэх, профайл

- Утасны дугаар + 4 оронтой кодоор нэвтэрнэ, бүртгүүлнэ (`#login`, имэйл шаардахгүй). Сервер (`functions/api/auth/`) кодыг шалгаж session үүсгэнэ, оролдлого хязгаартай (нэг дугаарт 15 минутад 6). Supabase-д имэйл заавал хэрэгтэй тул далд имэйл (`u-…@kinotube.pages.dev`) үүсгэдэг, хэрэглэгчид харагдахгүй, имэйл илгээгдэхгүй. Кодоо мартвал админ "Хэрэглэгч" табаас шинэ код өгнө; хэрэглэгч профайлаасаа кодоо солино. Хуучин имэйл бүртгэлүүд `#login-email`-ээр (цэсэнд холбоосгүй) нэвтэрч, профайлаасаа дугаар, код тохируулна. Хуучин `#register`, `#forgot` нь `#login` руу очно.
- Профайл (`#profile`): нэр (засна), утасны дугаар, код солих, үзэх эрх ба дуусах хугацаа, түрээсэлсэн кино, сарын эрх авах/сунгах, үзсэн түүх, төлбөрийн түүх (татгалзсан бол шалтгаан).
- Хэрэглэгчийн мэдээлэл, эрх Supabase-д. Үзсэн түүх, "Дараа үзэх" хөтөч дээр (localStorage), хэрэглэгч бүрт тусдаа.

## Төлбөр (банкны шилжүүлэг + Telegram)

1. Хэрэглэгч эрх сонгоод "Дансаар төлөх" дарна → сервер `KT-1234` гүйлгээний утгатай хүсэлт үүсгэнэ (дүнг `products`-оос).
2. Хаан банк `600005005303317077` (Батмэнд Хишигцогзол) руу яг тэр дүнг, утга дээр нь `KT-1234` гэж бичиж шилжүүлнэ. Данс `src/auth.js`-ийн `BANK`-д.
3. "Гүйлгээ хийсэн" дарахад (`/api/payments/<id>/submit`) Telegram бот админы группт ✅ Батлах / ❌ Татгалзах товчтой мессеж илгээнэ.
4. Админ дансаа шалгаад ✅ дарвал эрх шууд нээгдэж, хэрэглэгчийн дэлгэц өөрөө шинэчлэгдэн кино руу буцна. ❌ дараад мессежид хариу бичвэл тэр нь татгалзсан шалтгаан болно.
5. Админ хуудасны "Төлбөр" табаас ч батлах/татгалзах боломжтой. "Гүйлгээ хийсэн" дараагүй хүсэлт 24 цагийн дараа хүчингүй.

Эрх олгох бүх шийдвэр Postgres-ийн функцуудад (`approve_payment` г.м.), давхар дарсан ч нэг л удаа олгоно. Идэвхтэй эрх дээр дахин авбал дуусах хугацаан дээр нь нэмэгдэнэ.

## Олон ангитай кино ба Shorts

Кино хоёр хэлбэртэй: **хэвтээ** (16:9) ба **босоо** (9:16). Нэг ангитай (бүтэн 1–2 цаг) эсвэл олон ангитай (цуврал) байна.

- **Үнэгүй**: нэг ангитай кино эхний **5 минут**, цуврал эхний **2 анги** хүн бүрт (нэвтрээгүй ч). Цааш нь төлбөрийн сонголт (энэ кино/цуврал 3 хоног эсвэл сарын эрх) гарна. Сервер шалгана (`functions/api/video/[id].js`): эрхгүй хүнд 3-р ангиас цааш линк өгөхгүй, кинонд зөвхөн эхний хэсгийн байтыг өгнө.
- **Shorts** (`#shorts`, `#shorts-<id>/<анги>`) = олон ангитай **босоо** кино. Доош/дээш гүйлгэвэл өөр кино, **хөндлөн** гүйлгэвэл (эсвэл ← → товч) дараагийн анги. Анги дуусахад дараагийнх руу автоматаар шилжинэ. Нүүрний эхэнд Shorts мөр.
- **Хэвтээ цуврал** үзэх хуудсанд (`#watch-<id>/<анги>`) тоглуулагчийн доор ангийн жагсаалттай.
- Админ: **Цуврал / Shorts** таб → **Цуврал нэмэх** → нэр, хэлбэр, үнэ г.м. хадгална → доор нь **Анги нэмэх**: олон видео нэг дор сонгоход файлын нэрийн дарааллаар 1, 2, 3… анги болж хуулагдана. Анги бүрийн нэр (заавал биш), видео солих, устгах боломжтой. "Сайтад нийтлэх" сонгосон бол эхний анги хуулагдмагц цуврал нийтлэгдэнэ.
- Хуучин "киноноос тасалсан Shorts" бичлэгүүд migration-аар 1 ангитай босоо цуврал болсон (`supabase/migrations/20261101000001_series.sql`), видео нь `shorts/<id>.mp4` хэвээр.
- Локал хөгжүүлэлтэд `public/shorts.json`: босоо цувралууд, `episodes: [{ number, title, duration, video }]`.

## Админ

- `#admin` хаяг (эсвэл профайл дээрх "Админ" товч). `kinotubemn@gmail.com` бүртгэл админ (`#login-email`-ээр нэвтэрч профайлаас дугаар, код тохируулна). Бусад админыг "Хэрэглэгч" табаас нэмнэ. Эрхийг сервер (RLS, `admin_*` функц) шалгана.
- **Тойм** (`#admin-stats`): хэрэглэгч, идэвхтэй эрх, шалгах төлбөр, энэ сарын ба нийт орлого (сарын эрх, нэг кино тусдаа), их/бага үзсэн кино, шинэ хэрэглэгч.
- **Үзэлт** (`#admin-views`): кино бүрийг хэдэн хүн үзэж эхэлсэн, дуусгасан.
- **Кино / Цуврал** (`#admin-movies`, `#admin-series`): тус бүрээр нэмэх, цувралд анги нэмэх, засах, видео/зураг хуулах, нийтлэх, устгах (видео, зурагтай нь). Дээрх "Кино нэмэх" хэсгийг харна. Хуулалтын явц админы бүх таб дээр харагдана.
- **Хэрэглэгч** (`#admin-users`): утасны дугаараар хайж үнэгүй эрх олгох, кодоо мартсан хэрэглэгчид шинэ код өгөх/сунгах, дуусах өдөр тохируулах, цуцлах, бүртгэл хаах, админ болгох. Хаагдсан хэрэглэгч кино үзэж, төлбөр хийж чадахгүй.
- **Төлбөр** (`#admin-payments`): шалгах, батлагдсан, татгалзсан хүсэлтүүд. Вэбээс батлах/татгалзах.

## Байршуулалт (production)

- **Cloudflare Pages** (`kinotube` төсөл, GitHub-тай холбосон): build `npm run build`, output `dist`. `main` руу push хийхэд https://kinotube.pages.dev шинэчлэгдэнэ. `functions/` хавтас автоматаар сервер болно.
- Cloudflare Pages → Settings → Variables and Secrets: `.env.example` дахь бүх утга (`VITE_*` нь build-д ч хэрэгтэй).
- **Supabase**: GitHub интеграцаар `main`-д орсон `supabase/migrations/` автоматаар хэрэгжинэ (эсвэл SQL Editor-т файлыг хуулж ажиллуулна). Authentication → Email: "Magic Link" загварт `{{ .Token }}` код харуулна.
- **Telegram webhook** (нэг удаа): `TELEGRAM_BOT_TOKEN=... TELEGRAM_WEBHOOK_SECRET=... npm run telegram:webhook`.
- GitHub Actions (`.github/workflows/ci.yml`) push болон PR бүрт build шалгана.
